# Encrypted Math

This site implements the [Paillier cryptosystem](https://en.wikipedia.org/wiki/Paillier_cryptosystem) a form of additive [Homomorphic Encryption](https://en.wikipedia.org/wiki/Homomorphic_encryption) that also implements public key cryptography.

This site uses [Paillier Bigint](https://github.com/juanelas/paillier-bigint) for the Paillier cryptosystem.
